# Halloween UX Guidelines

## Tone & Voice
When generating Halloween-themed content, maintain a balance between spooky fun and professional compliance messaging.

### Flavor Text Examples
- **Scan Starting**: "Summoning the spirits..." / "Awakening the code ghosts..."
- **Scan Complete**: "The haunting is complete" / "All spirits accounted for"
- **Critical Violation**: "A vengeful spirit lurks here" / "This ghost won't rest easy"
- **Fix Applied**: "Ghost banished!" / "Spirit laid to rest"
- **Clean Scan**: "No ghosts detected" / "The code is blessed"
- **Healthy Repo**: "Protected by ancient wards" / "Ghost-free zone"

### Microcopy Patterns
- Replace "violations" with "hauntings" or "spirits"
- Replace "scan" with "séance" or "spirit check"
- Replace "fix" with "exorcism" or "banishment"
- Replace "critical" with "vengeful" or "malevolent"
- Replace "healthy" with "blessed" or "protected"

### Professional Balance
- Keep technical terms visible (e.g., "Critical Violation (Vengeful Spirit)")
- Don't obscure important information with theme
- Provide theme toggle for users who prefer standard UI
- Maintain all existing functionality

## Animation Guidelines
- Ghosts should float gently, not distract
- Particle effects should be subtle and brief
- Sound effects must be opt-in and low volume
- Respect system motion preferences
- Keep performance smooth (60fps target)

## Color Usage
- Use purple/orange gradient for backgrounds
- Red glow for critical issues (maintains urgency)
- Green for healthy states (maintains positive association)
- White/pale colors for ghost elements
- Black for depth and contrast
